# ANDY BI Workspace Request Checklist

## Informacoes para TI/BI

- Plataforma BI oficial.
- Nome do workspace Dev.
- Nome do workspace Homolog.
- Nome do workspace Prod.
- Owner funcional.
- Owner tecnico.
- Dono do dado.
- Aprovador de seguranca.
- Grupos corporativos por perfil.
- Politica de RLS/ABAC.
- Politica de sensibilidade/classificacao.
- Periodicidade de refresh.
- Gateway ou mecanismo equivalente.
- SLA de operacao.
- Retencao de logs.
- Plano de rollback.
- Canal de suporte.

## Evidencias do ANDY

- Data contract.
- Semantic model.
- RLS/ABAC policy.
- Relatorio piloto.
- Paridade desktop/XLSX vs BI.
- Manifesto de lote.
- Hash do pacote.
- Validation report.

## Regras

- Usar repositorio privado.
- Revisao humana antes de publicar.
- Nao incluir dados reais em pacote versionavel.
- Nao incluir credenciais em configs versionadas.
