# ANDY Threads - Perguntas de Vizinhança de Alimentadores

Este documento lista as perguntas que precisam ser respondidas antes de promover pares exploratórios para vizinhança física confirmada.

1. Quais ALs são fisicamente vizinhos?
2. Quais chaves permitem transferência?
3. Qual direção de transferência é conhecida?
4. Existe diagrama unifilar?
5. Qual transformador alimenta os pares?
6. O horário da manobra manualmente identificada é conhecido?
7. Existe log SCADA ou operação?

## Regra de Uso

- MOS AL3/AL4 é par declarado apenas para o laboratório autorizado.
- OSO1 não tem pares confirmados no exemplo; sem configuração humana, só pode rodar em modo exploratório.
- O modo exploratório nunca deve chamar pares de “vizinhos confirmados”.
- Nenhum candidato vira manobra confirmada sem validação humana ou evidência SCADA.
